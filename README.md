# AI-Based Medical Assistance System for Railway Passengers

## Project Overview
This is a hybrid project that combines Python, Streamlit, Arduino, and Voice Recognition to provide basic medical assistance. The user speaks their symptoms, and the system identifies the disease, suggests a medicine, and activates the corresponding LED on Arduino. In emergency situations, the buzzer is activated.

## Features
- Voice-based symptom input
- Disease detection
- Medicine recommendation
- Emergency alert using buzzer
- Arduino LED indication
- Streamlit user interface

## Technologies Used
- Python
- Streamlit
- Arduino Uno
- JSON
- SpeechRecognition
- PySerial
